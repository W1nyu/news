# 2단 읽기 · 라이트 기본 · 읽기 편의 기능 (2026-10-01)

## 목표

PC 브라우저에서 하루 최대 72건을 빠르게 훑고 골라 읽게 한다. 카드 격자를 **제목 목록 + 기사 상세** 2단 구조로 바꾸고, 기본 테마를 라이트로, 안 읽은 기사 중심 탐색·키보드 단축키·글자 크기·제목·링크 복사를 더한다. 수집기·서버(Python)와 보고서 JSON은 바꾸지 않는다.

## 결정 (사용자 확인)

- 사용 기기: 이 PC 브라우저만. 서버 접속 범위(127.0.0.1)는 그대로.
- 테마: 처음 열면 라이트. 저장 키를 `briefing.theme.v2`로 바꿔 예전 `v1`(시스템 등) 선택은 무시하고 라이트에서 시작한다. 다크·시스템은 직접 고를 때만.
- 배치: 2단 읽기(A안). 좁은 창은 목록 펼치기.
- 추가 기능: 안 읽은 기사 중심, 키보드 단축키, 글자 크기, 제목·링크 복사 — 네 가지 모두.
- 상세에 띄우면 읽음으로 친다(원문을 열어도 읽음). 되돌리기는 `m`/버튼.

## 화면 구조

- **앱바(sticky)**: 브랜드 | 보기 메뉴 | 키워드 설정 | 지금 수집.
- **보기 메뉴**(popover): 테마 라이트/다크/시스템, 글자 크기 작게/보통/크게. 버튼 `aria-pressed`로 현재 값 표시. 기존 순환 테마 버튼은 제거.
- **제목 줄**: 한 줄로 축소(h1 + 갱신 시각 + 14일 막대).
- **오늘 보고서 없음 배너, 툴바**(날짜·검색·기간·언론사 + `안 읽은 것만` 토글): 기존 위치, 스크롤 시 지나감.
- **섹션 탭(sticky, 앱바 아래)**: `전체 41 · 금융 5 …` — 숫자는 현재 목록 기준 안 읽은 수(0이면 생략). 저장함은 저장 건수.
- **≥1024px**: 왼쪽 목록(약 42%) + 오른쪽 상세(sticky, 앱바+탭 아래, 자체 스크롤).
- **<1024px**: 한 줄 목록. 고른 행 아래에 같은 상세 내용이 펼쳐진다(한 번에 하나). 헤드라인은 목록 위 가로 스크롤 한 줄.
- 상세와 펼침은 같은 마크업을 두 곳에 그리고 CSS 미디어 쿼리로 하나만 보인다(JS에 화면 폭 분기 없음).

### 목록

- `전체`·최근 7일: 섹션 순서대로 묶음. 묶음 머리 `금융 · 안 읽음 5/9 · 모두 읽음`.
- 섹션 탭·검색·저장함: 묶음 없이 한 목록. 머리에 `안 읽음 n/m · 모두 읽음`.
- 행: 안 읽음 점 + 제목(키워드 강조, 2줄 말줄임) / `언론사 · 시각 [· 날짜] [· 관련 n] [· ★]`. 읽은 행은 흐리게, 고른 행은 brand weak 배경.
- 행은 `<button data-select>`. 고른 행을 다시 누르면 선택 해제.
- 한 번에 80건, 넘으면 `더 보기`(보고서 하루치는 항상 한 번에 보인다).

### 상세

- 섹션 배지, 제목(원문 링크), `언론사 · 발행 시각`.
- 버튼: `원문 열기`, `저장`/`저장됨`, `링크 복사`, `안 읽음으로`/`읽음으로`, (검색·저장함·7일 보기일 때) `YYYY-MM-DD 보고서 보기`.
- 요약 문장(키워드 강조), 관련 보도는 접지 않고 목록으로 표시(언론사·제목 링크·시각, 읽음 표시).
- 선택이 없을 때(≥1024px)는 **개요**: 헤드라인 6건(키워드 점수 → 최신순, 기존 규칙), 섹션별 `안 읽음/전체`, 단축키 안내 한 줄. 검색·저장함에서는 `n건` 안내만.

## 읽기 상태

- 상세에 표시(클릭·단축키·헤드라인), 원문 링크 열기(클릭·가운데 클릭·Enter) → 읽음.
- `안 읽음으로`/`m` → 읽음 목록에서 제거. `briefing.read.v1` 형식·2000건 한도 유지.
- `안 읽은 것만`(`briefing.unread-only.v1`): 켜져 있으면 읽은 기사를 숨기되, 이번 화면에서 방금 읽은 기사(`state.keep`)는 남긴다. 섹션·날짜·검색어·언론사·기간·토글을 바꾸면 `keep`을 비운다.
- `모두 읽음`: 해당 묶음(필터 적용 후)의 기사를 모두 읽음 처리. `keep`에 넣지 않으므로 `안 읽은 것만`에서는 사라진다.
- 헤드라인으로 고른 기사는 필터(섹션·검색·언론사)를 풀고 `keep`에 넣어 항상 보이게 한다.

## 키보드 단축키

입력창·select·textarea·열린 dialog 안에서는 무시하고, Ctrl/Alt/Meta 조합도 무시한다. 버튼·링크에 포커스가 있을 때 Enter는 기본 동작을 따른다.

| 키 | 동작 |
|---|---|
| `j` / `↓` | 다음 기사 |
| `k` / `↑` | 이전 기사 |
| `Enter` / `o` | 원문 새 탭 + 읽음 |
| `s` | 저장 전환 |
| `c` | 제목·링크 복사 |
| `m` | 읽음 전환 |
| `u` | 안 읽은 것만 전환 |
| `0` / `1`~`8` / `9` | 전체 / 섹션 / 저장함 |
| `/` | 검색창으로 |
| `Esc` | 선택 해제(검색창에서는 검색창 벗어남) |
| `?` | 단축키 도움말 dialog |

이동 순서는 화면에 그려진 목록 순서(`state.visible`). 이동 시 고른 행을 `scrollIntoView({block:'nearest'})`.

## 글자 크기

`<html data-font="s|l">`(보통은 속성 없음) → `--reading-scale` .9 / 1 / 1.15. 목록 제목·메타, 상세 제목·요약·관련 보도, 개요 글자에 `calc(토큰 × scale)` 적용. 저장 `briefing.font.v1`. `<head>` 인라인 스크립트가 테마와 함께 스타일 로드 전에 적용한다.

## 제목·링크 복사

형식 `제목 (언론사)\n원문 URL`. `navigator.clipboard.writeText` 실패 시 숨은 textarea + `execCommand('copy')`. 결과는 화면 아래 토스트(`role=status`, 2초): `제목과 링크를 복사했습니다.` / `복사하지 못했습니다.`
